# DocAppointix

## Overview

DocAppointix is an AI-powered healthcare platform that manages the complete patient journey, from symptom assessment and doctor recommendation to consultation and recovery monitoring.

The platform integrates AI-driven triage, real-time communication, clinical documentation, and post-treatment tracking into a single workflow to support continuous patient care.

---

## Key Highlights

* Built a full-stack healthcare platform using the MERN stack
* Integrated Google Gemini API for AI-powered symptom analysis and triage
* Implemented urgency classification (Red, Yellow, Green) for patient prioritization
* Developed AI-assisted doctor recommendation based on symptoms, urgency level, and specialization
* Enabled real-time doctor–patient video consultation using ZegoCloud and Socket.io
* Built AI-assisted clinical note generation during consultations
* Implemented recovery tracking with progress visualization and medication reminders

---

## Features

### Pre-Consultation

* Symptom input through text and image upload
* AI-powered symptom analysis
* Urgency classification and specialty mapping
* AI-assisted doctor recommendation
* Emergency case prioritization

### During Consultation

* Real-time doctor–patient video consultation
* Split-screen intelligent workspace
* AI-assisted clinical note generation
* Dynamic doctor collaboration
* Interactive whiteboard support

### Post-Consultation

* Digital prescription management
* Daily recovery tracking and patient feedback
* AI-based progress visualization
* Medication reminders
* Patient health monitoring dashboard

---

## System Workflow

Patient → Symptom Input → AI Triage & Urgency Classification → Doctor Recommendation → Video Consultation → Clinical Documentation → Digital Prescription → Recovery Tracking
